# Executioner's Run

*Old City, Port Nyanzaru*

- Stone-lined, 15' deep, 50' wide, 200' long
- Used to be an arena for a highly competitive ball game
- Velociraptors, panthers, and juvenile allosauruses against convicted criminals
- Those who scramble up the ropes on the other side earn their freedom — bets are placed
- Some earn fame from multiple runs
