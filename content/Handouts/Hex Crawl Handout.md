# Hex Crawl Handout

#### Travel

- **Navigator** makes a Survival check or the party becomes lost. Advantage for previously revealed hexes.
    - **DC 10:** Coasts and lakes
    - **DC 15:** Jungles, mountains, rivers, swamps, wastelands
    - When lost, the party moves to an unknown adjacent hex. Location is revealed on the next day's successful Survival check.

| Hexes | Travel | Bonus | Roll         | Other                                                       |
| ----- | ------ | ----- | ------------ | ------------------------------------------------------------ |
| 0     | Slow   | +5    | **1d4**: 1-2 | Long Rest                                                     |
| 1     | Slow   | +5    | **1d4:** 3-4 | Long Rest                                                     |
| 1     | Normal | 0     | -            |                                                                |
| 1     | Fast   | -5    | **1d4:** 1-2 |                                                                |
| 2     | Fast   | -5    | **1d4:** 3-4 |                                                                |
| 2     | Canoe  | 0     |              | Only on rivers and lakes. Unusable in tropical storms.        |

- **Short Rest** — works as normal. 1 hour, expend hit dice.
- **Jungle Rest** — a night in the jungle. Same benefits as a short rest, but prevents exhaustion.
- **Long Rest** — works as normal. Only possible on a slow travel day.

---

- **Food** — must consume a ration per day or receive one point of exhaustion.
- **Foraging** — only two people can forage each day.
- **Encounters** — pre-rolled and set for each hex.
- **Weather** — rolled at the beginning of each day. Some weather events are hex-specific.
